# ПРОЖИВИ

Интерактивный сезонный сайт-конструктор личной осени.

## Принципы продукта
- бумажный блокнот остаётся в центре опыта;
- пользователь выбирает и переставляет главы/маршруты;
- выполнение точек сохраняется локально;
- free-версия ограничена, premium-контент явно обозначен;
- дизайн: светлый editorial / sketchbook / urban archive без шаблонного AI-вида.

## Разработка
Проект на React + Vite. Первая версия работает без платного backend: прогресс хранится в браузере. Позже авторизация и синхронизация будут вынесены в отдельный бесплатный/недорогой backend.
